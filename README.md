# NumPy Data Explorer

## Overview

NumPy Data Explorer is a beginner-fiendly Python project developed as part of my Data Science Internship at Syntecxhub.

The project demonstrates the fundamental features of NumPy, including array creation, indexing, slicing, mathematical operations, statistical analysis, reshaping, broadcasting, saving and loading arrays, and perfomance comparison between NumPy arrays and standard Python lists.

## Features

- Create and display NumPy arrays
- Access elements using indexing
- Extract elements using slicing
- Perform mathematical operations on arrays
- Perform statistical operations such as; Mean, Minimum, Maximum, Sum and    Standard deviation
- Create and work with 2D arrays
- Reshape arrays
- Demonstrate broadcasting
- Save NumPy arrays to '.npy' files
- Compare NumPy perfomance with standard Python lists

## Technologies Used

- Python
- NumPy
